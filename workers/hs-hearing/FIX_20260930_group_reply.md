# 2026-09-30 加盟店のグループで返事が出ない、答えが取り込まれない

## 起きたこと

hs-partner-001(リフォーム職人株式会社)の HORIZON グループで、森下さまと堤さまが、こちらの設問を貼って「↓」の下に答えてくださった。先頭に @HORIZON SHIELD のメンション。公式アカウントは何も返さず、答えも取り込まれなかった。

## 原因は3つ

1. hs-kira-line がグループでは黙る作りだった(2026-08-20 HS-KIRA-GROUP-SILENT)。hearing の窓口が返事の文を作っても、ここで捨てていた。呼ばれた発言まで黙っていた。
2. 値段の話を訊いた設問(「他社より高いと言われたとき」「仕入れ値の動き」)への答えに「金額」「価格」の語が入り、金額の門が「料金の問い合わせ」と読んで取り込まなかった。聞き方と門がぶつかっていた。1対1でもメールでも同じ。
3. 設問を貼って答える形で、貼った設問の「教えてください」「大丈夫です」を見て、全体を「質問」と読んで取り込まなかった。

## 直したこと

- hs-hearing(concierge.js の splitEchoReply ほか、hearing.js の handlePartnerInbound)
  - 先頭の @HORIZON SHIELD を外し、最初の「↓」だけの行で、貼った設問と答えに分ける。判定と取り込みは答えの部分で行う。返事のログには生の全文を残す。
  - 返事待ちの設問が値段の話か、相手が設問を貼って答えているときは、答えの中のお金の語で門を閉じない。ただし掲載料・支払い・いくらか等、こちらへのお金の問い合わせは、これまでどおり大賀に回す。値段の話を訊いていないときの一文も、これまでどおり大賀に回す。
  - 設問を貼った下の答えは、終わりが問いの形のときだけ質問とする。
  - 回答への機械の返事にお金の語が出たら、料金の案内ではなく受領の定型に替える。
  - 設問を貼って答えてくださったときに「取り違えている可能性」とは返さない(当て直しはこちらの手間)。
- hs-kira-line
  - グループでも、公式アカウントを @ で呼んだ発言(mention.isSelf、無ければ本文の @HORIZON SHIELD)にだけ、hearing の窓口の文を reply で返す。呼ばれていない発言には、これまでどおり黙る(取り込みはする)。
  - 署名の門が fail-open だった(署名なし、鍵なし、検証が投げた、の3つとも通していた)。全部 401 にした。
  - /health の version を v10-group-reply-20260930 にした(配った版の確かめ用)。

## 試験

- workers/hs-hearing/echo_reply_test.mjs(31 件)。実文2通を書き起こして通す。直す前のコードでは 9 件落ち、森下さまの答えは money、ロールスクリーンの答えは question になる(実際に起きたことの再現)。
- workers/hs-kira-line/group_reply_test.mjs(14 件)。直す前のコードでは 7 件落ちる(署名なしで 200、呼ばれても返さない)。
- hs-hearing の run_all は 15/15。CI(deploy-hs-hearing.yml)に echo_reply_test を足した。
